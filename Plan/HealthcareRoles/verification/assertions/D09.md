## DECISION:D09:rule

**Original:** Coding specialist assigns supported codes; clinical ambiguity goes back to responsible author.

**Verdict:** SUPPORTED_GENERAL_DESCRIPTION

**Reason:** The occupational description supports code assignment from clinical information; documentation/denial example supports collaboration.

**Alternatives:** Pre-service clarification, coding, CDI and downstream claim correction can be separate work.

**Complexity / unresolved:** The exact coding standard/query process must be specified; coding alone is not clinical diagnosis or payer adjudication.

- [R08](https://journal.ahima.org/AMP_EDN/383/AHIMA-Releases-Denials-Management-Toolkit-1776.amp.html) — HTML p block 1; access: retrieved. Passage anchor: `coding`.
