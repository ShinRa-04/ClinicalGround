# U01 assertion review

[Audit index](../README.md)

## ROLE:U01:mission:01

**Original:** Create and route a reviewable request record for the reviewing organization.

**Verdict:** INTERPRETIVE_FUNCTION_SUMMARY

**Reason:** The mission summarizes a modeled function from the evidence and does not create an official occupation or grant authority. The program explicitly assigns intake, data entry, information requests, routing and notification to nonclinical staff.

**Alternatives:** The same program allows limited approvals under explicit criteria and assigned benefit-only actions; intake is not necessarily a no-decision clerical role.

**Complexity / unresolved:** This is organization-specific delegation. Clinical medical-necessity denial is treated differently from benefit-only decisions; do not infer national authority.
