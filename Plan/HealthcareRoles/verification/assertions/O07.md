## ROLE:O07:mission:01

**Original:** Translate documented services and diagnoses into appropriate codes.

**Verdict:** INTERPRETIVE_FUNCTION_SUMMARY

**Reason:** The mission summarizes a modeled function from the evidence and does not create an official occupation or grant authority. Coding supported clinical information is directly documented; queries and clinician clarification are supported by the documentation example.

**Alternatives:** Pre-service code clarification and downstream claim coding differ.

**Complexity / unresolved:** Code assignment is not independent diagnosis or coverage adjudication.
