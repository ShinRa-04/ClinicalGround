# First implementation contract

Status note, October 19: this file records the initial shared interfaces. Actual code adds transactional owner/fence keyword checks, bound-scope tool clients, deterministic context projection/rehydration, sequential role helpers and the direct Harbor launcher. `core_implementation` and `implementation_finish` (GPT-6 Luna high) supplied code; the originally proposed separate runtime/integration agent slots below did not run. Root handled review, localhost HTTP tests, documentation and final integration. See VERIFICATION.md for executed checks; automatic new resource identity binding and live benchmark validation remain unimplemented/unperformed.

This is an engineering implementation over the supplied environment, not a second hospital simulator. Runtime model IDs are explicit user configuration; the coding agents' Luna selection is not a runtime model selection.

Python 3.11+, standard-library core. Package `health_harness/` in this folder, runnable with `python -m health_harness`. No changes to official checkouts, downloaded payloads or protected sources. No provider requests, Docker startup or scored runs during development. Tests use synthetic data and local fakes only.

## Interfaces shared by implementers

`models.py` exports frozen `Scope(environment, task, organization, principal, patient, case)` (all nonempty strings), `ToolSpec(name, description, input_schema, effect='read', identity_fields=())`, `ToolCall(id, name, arguments)`, `ModelReply(content='', tool_calls=(), usage={})`, `Limits(max_model_calls=30, max_tool_calls=100, max_context_chars=60000, max_output_tokens=4096)`. Effects: read/write. Dataclass properties and validation may be added without breaking these constructors. Scope has `key` (stable digest), `to_dict()`.

`store.py` exports `CaseStore(path)` with `open_case(scope, instruction, domain)`, `load_case(scope) -> dict`, `save_case(scope, state, expected_version) -> int`, `claim(scope, owner, ttl_seconds=60) -> int` (fence), `release(scope, owner, fence)`, `assert_claim(scope, owner, fence)`, `reserve_action(scope, action_id, tool, arguments, effect) -> dict`, `finish_action(scope, action_id, result)`, `unknown_action(scope, action_id, reason)`, `actions(scope) -> list[dict]`, `close()`. Case state starts `version=0`, `messages=[]`, `obligations=[]`, `evidence=[]`, `model_calls=0`, `tool_calls=0`, `status='ready'`; immutable instruction/domain/scope and persisted budgets. `save_case` increments version, rejects scope/instruction/domain replacement. Action record has id/tool/arguments/effect/status/result; same ID conflicting payload rejected, completed can read back, pending/unknown writes must never replay automatically. All store queries use full scope key. Errors `IsolationError`, `ConflictError`, `UnknownOutcomeError`, `BudgetError` in `models.py`.

`roles.py`: immutable approved definitions, loads a packaged copy of the blueprint's 66 contracts, `roles_for(domain) -> list[dict]`, `system_prompt(domain, scope, composition='combined') -> str`. Domains PA/UM/CM, composition combined/helpers/team. No patient-derived shared learning or dynamic prompt edits.

`engine.py`: `Harness(store, model, tools, limits=None, composition='combined')`, `run(scope, instruction, domain, resume=False) -> dict`. Model protocol synchronous `complete(messages, tools: list[ToolSpec], *, max_output_tokens) -> ModelReply`. Tools protocol synchronous `list_tools() -> list[ToolSpec]`, `call(name, arguments) -> JSON-compatible value`. Engine assembles only this case, validates tool args (schema and declared identity_fields before call), enforces bounds, durable action journal, fresh model request messages (no threads), context budget preserving unresolved obligations/source pointers. Helpers/team are bounded read-only inferences with same aggregate budgets; owner alone executes effects. Completion must record claim + supporting observed action/evidence, otherwise unresolved (not official scoring). Unknown effect result blocks automatic continuation/replay; surface actionable status. No model-generated assertion becomes clinical truth.

`providers.py`: `OpenAICompatibleModel(model, base_url, api_key, timeout=60, reasoning_effort=None)` implements above protocol using explicit stateless Chat Completions requests; no default credentials lookup in imports. `ScriptedModel(replies)` for deterministic offline demos/tests. Do not retry requests silently.

`tools.py`: `ToolRegistry` merges tools, namespace collision fails; `MCPClient(url, timeout=30)` implements list_tools/call, Streamable HTTP JSON-RPC initialize/session/notifications, JSON/SSE decoding, pagination, no mutation retries. Optional SDK is allowed only if lazy and documented. `WorkspaceTools(root)` exposes confined local file operations; no shell/unrestricted host access. `schema.py` exposes `validate_arguments(spec, arguments, scope)` for JSON schema subset and declared identity paths; unsupported schemas fail explicitly rather than silently bypass validation. Unknown effect defaults write unless explicit readOnlyHint true; annotations are hints, not authorization proof. Actual MCP server controls domain/access. Narrow resource identifiers are opaque: do not claim validating case_id alone proves patient authorization.

`cli.py`/`__main__.py`: offline synthetic demo default command, explicit run config JSON with scope/instruction/domain/model/endpoint/storage/workspace/composition/limits; live run requires explicit `--live`, reads configured key env name without printing secrets. Resume explicit. Exit/status must distinguish blocked/exhausted/error/unresolved from complete. Config and logs local-only under ignored `runs/`; no protected content in tracked fixtures. `chi_bench.py` optional Harbor BaseInstalledAgent adapter for pin 4444a07; lazy imports so ordinary offline CLI works without Harbor. Install ships THIS package into container, uses actual supplied MCP URLs, explicit case scope/config, does not read verifier/expectations/fixtures. External harness import path documented; no upstream patch.
